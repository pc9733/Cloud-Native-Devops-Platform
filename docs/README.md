# Cloud-Native-DevOps-Platform Documentation

This directory contains guides and best practices for setting up and operating the Cloud-Native-DevOps-Platform.

## Available Guides
- **environment-strategy.md**: How to manage dev, staging, and prod environments using Terraform workspaces and Kubernetes namespaces.
- **gitops-flux.md**: Step-by-step instructions for bootstrapping GitOps deployments with Flux on EKS.
- **monitoring-logging.md**: Quickstart for deploying Prometheus, Grafana, and Alertmanager for monitoring and logging.
- **secrets-management.md**: Secure secrets delivery using AWS Secrets Manager, SOPS, and Kubernetes External Secrets Operator.

## Usage
1. Review each guide for setup instructions and best practices.
2. Follow the steps to provision infrastructure, deploy workloads, and secure your platform.
3. Customize the examples to fit your organization's requirements.
